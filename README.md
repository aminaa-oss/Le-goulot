# Le Goulot 🍷

Plateforme de réservation et de gestion de soirée pour les clubs et bars, avec système d'abonnements et fonctionnalités de planification.

## 📋 Fonctionnalités

### Pour les utilisateurs
- Système d'abonnements multi-niveaux (Glouglou, Premium, Ticket à durée limitée)
- Réservation de tables en temps réel
- Visualisation de la densité de population des établissements
- Suggestions personnalisées de soirées
- Création d'organigrammes de soirée
- Parcours optimisés (barathons)

### Pour les établissements
- Panel de statistiques en temps réel
- Gestion des réservations
- Outils de planification de capacité

## 🏗️ Architecture

Le projet est structuré en trois parties principales :

1. **Backend** - API RESTful en Node.js/Express avec base de données MongoDB
2. **Frontend** - Application web en React
3. **Mobile** - Application mobile en React Native
